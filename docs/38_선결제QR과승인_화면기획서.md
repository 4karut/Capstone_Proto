# 한턱 선결제 이용 QR·승인 화면 기획서

선택한 선결제 이용 버튼 또는 마이페이지의 본인 이용 요청에서 진입한다.

상단 뒤로가기·선결제 이용 QR 제목 아래 가게 이름, 그룹과 진행 상태를 표시한다. 표준 QR, 6자리 이용 코드와 복사 버튼, 코드 유효시각, 선택한 선결제 잔액을 보여준다. 프로토타입의 코드는 발급 후 10분간 유효하며 실제 카메라 스캔은 가게 관리의 코드 입력으로 대신한다.

상태는 가게 확인 대기 → 결제 승인 대기 → 사용 완료로 바뀐다. 사장님이 금액을 요청하면 요청 금액을 크게 표시하고 금액 확인·결제 승인 버튼을 제공한다. 이용자가 금액을 직접 입력하거나 수정하지 않는다.

승인 시 현재 소속·가게·잔액·사용 기한·코드 유효성을 다시 검사한다. 승인 전에는 금액을 차감하거나 사용 완료 알림을 만들지 않는다. 다른 회원이 먼저 사용해 잔액이 부족해졌다면 승인을 막고 안내한다. 종료일 한국 시간 23:59까지 이용할 수 있다.

성공하면 선택한 후원의 사용액을 한 번만 늘리고 잔액을 줄인다. 후원자와 해당 가게에 사용 완료 알림을 생성하고 감사 메시지 작성으로 이동한다. 완료한 코드를 다시 처리해도 중복 차감하지 않는다.

승인 전 이용 요청 취소는 잔액을 유지한다. 취소·만료된 코드는 사용할 수 없으며 조건이 맞으면 새 QR을 발급할 수 있다. 완료한 결제를 재조회하면 영수증과 감사 메시지 확인·작성 버튼을 보여준다.

완료 후 가게에서 결제를 취소하면 상태를 결제 취소로 표시하고 원래 선결제에 사용 금액을 복구한다. 이용자에게 취소 사유·시각·복구 금액·잔액·기한을 보여준다. 기존 QR 재승인과 새 감사 작성은 막고 이미 보낸 감사 메시지만 확인할 수 있다. 다시 이용하려면 새 QR을 발급한다. 현재 부분 취소·실제 현금 환불은 지원하지 않는다.

QR에는 로그인 정보나 개인정보를 담지 않고 프로토타입 이용 코드만 인코딩한다. 실제 운영 시 서버 검증과 매장 스캔 연동은 별도 구현해야 한다.
