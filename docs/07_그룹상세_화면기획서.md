# 한턱 그룹 상세 화면 기획서

검색에서 선택한 그룹의 소개, 후원 버튼과 가입 방법을 확인한다. 가입한 그룹을 열면 같은 소개 아래에 소속 그룹의 선결제 가게를 표시한다.

## 배치와 즐겨찾기

상단에 뒤로가기, 제목, 하트 버튼을 둔다. 하트는 최초에 테두리로 표시하고 누르면 빨간색으로 채워 즐겨찾기 그룹으로 지정한다. 다시 누르면 해제한다.

즐겨찾기는 계정별로 구분하며 가입 여부와 독립적이다. 즐겨찾기를 지정해도 소속으로 추가하지 않는다. 현재 실행 중 화면 이동과 로그아웃 후 재로그인에도 유지되며 새로고침하면 초기화된다.

지정한 그룹은 하단 별표의 즐겨찾기 그룹 탭에서 확인한다. 그 목록을 눌러도 검색과 같은 상세 화면을 연다.

소개 영역은 왼쪽에 굵은 그룹 이름과 낮은 채도의 일반 굵기 대표 태그, 오른쪽에 썸네일을 표시한다. 이름 아래에 한 줄 소개, 그 아래에 카테고리와 나머지 태그, 공개 코드를 표시한다.

## 후원과 신청

태그 아래, 그룹 신청 위에 후원하기 버튼을 둔다. 두 버튼은 같은 전체 너비, 높이 54, 동일한 모서리 형태로 표시한다. 후원은 연한 주황색, 신청은 주황색으로 구분한다.

후원하기는 금액 후원과 선결제 후원을 고르는 화면으로 이동한다. 각 입력 화면에서 확인하면 프로토타입 결제가 완료되고, 완료 화면의 확인은 홈으로 돌아간다.

미신청 일반 그룹의 신청은 자기소개 팝업을 열고, 잠긴 그룹은 초대 코드 팝업을 연다. 승인 대기는 재신청을 막는다. 가입한 그룹은 신청 버튼 대신 가입 상태와 선결제 가게를 표시한다.
