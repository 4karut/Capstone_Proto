# 한턱 가게의 그룹별 선결제 화면 기획서

가게 선결제 관리에서 특정 그룹을 선택한다. 상단 뒤로가기·그룹별 선결제 제목 아래 그룹 이름을 굵게 표시하고 가게 이름을 함께 표시한다.

선결제 후원 각 건을 별도 카드로 표시한다. 기한이 빠른 순서로 선결제 번호·사용 가능/기간 종료/전액 사용/사용 전 상태, 남은 금액, 총액과 사용액, 사용률 막대, 사용 기한, 시작일부터 종료일까지의 기간을 표시한다. 만료된 잔액에는 사용할 수 없다는 안내를 덧붙인다.

같은 가게·그룹에 10만원씩 두 번 후원해도 개별 잔액·기한을 합치거나 덮어쓰지 않는다. 예시 가게 1은 예시 그룹 3에 총 10만원 중 35,000원 사용, 잔액 65,000원, 기한 2026.11.27인 초기 내역을 제공한다.

본인 소유 가게의 해당 그룹 내역만 보여준다. 그룹원 여부로 가게 주인의 관리를 제한하지 않는다. 종료일 한국 시간 23:59까지 이용 가능하다. 이 화면은 현황 조회 화면이며 QR 결제 처리에서 사장님이 요청하고 이용자가 승인한 금액을 해당 건의 사용액·잔액에 반영한다. 사장님이 완료한 사용을 취소하면 그 결제 금액만 원래 건에 복구하고 기한은 유지한다. 현금 환불은 후속 설계 대상이다.
