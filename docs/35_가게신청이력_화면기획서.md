# 한턱 가게 신청 이력 화면 기획서

신청자는 마이페이지의 최신 신청 카드에서 신청 정보·이력 보기를 누른다. 관리자는 재신청 심사 상세의 이전 신청·반려 이력 확인에서 진입한다.

상단 뒤로가기·가게 신청 이력 제목 아래 총 신청 차수를 표시한다. 같은 신청에서 이어진 차수별 기록을 최신순으로 나열한다. 신청자가 다른 가게를 별도로 신청한 기록은 섞지 않는다.

각 카드에는 차수·상태(심사 대기/반려/승인 완료), 가게 이름, 사업자등록번호, 주소, 카테고리, 전화번호, 소개, 신청일시, 처리된 경우 심사일시를 표시한다. 날짜와 시간은 한국 시간으로 표시한다. 반려된 차수에는 당시 사유를 온전히 보여준다.

각 차수의 제출 정보와 반려 사유를 수정본으로 덮어쓰지 않는다. 새 차수 승인 후에도 이전 차수는 반려 상태로 남는다. 이 화면은 조회 화면이며 재신청은 마이페이지에서 최신 반려 건을 선택한다.

신청자 본인과 관리자만 조회할 수 있다. 다른 사용자의 신청·사유는 공개하지 않는다. 모든 이력은 현재 프로토타입의 실행 중 메모리에 저장하며 새로고침·재시작 시 초기화된다.
