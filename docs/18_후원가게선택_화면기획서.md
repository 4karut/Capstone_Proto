# 한턱 후원 가게 선택 화면 기획서

선결제 후원의 가게 입력란을 누르면 진입한다. 일반 가게 찾기와 마찬가지로 소속 그룹이나 선결제 이용 가능 여부와 관계없이 등록된 전체 가게에서 선택한다. 이 화면의 가게 카드는 상세 조회 대신 후원 입력란에 가게를 선택하는 용도다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 뒤로가기와 선결제 가게 선택 제목 | 선택하지 않고 입력 화면으로 복귀 |
| 2 | 가게 이름 검색란과 검색 아이콘 | 검색 또는 키보드 검색으로 실행 |
| 3 | 검색창 옆 하트 모양 정사각형 버튼 | 후원용 즐겨찾기 가게 선택 화면으로 이동 |
| 4 | 전체 가게 또는 검색 결과 개수 | 빈 검색은 등록된 전체 가게 표시 |
| 5 | 가게 카드 | 이름·주소·기존 사진 표시, 누르면 해당 가게 선택 |

검색은 가게 이름의 부분 일치이며 공백을 제외하고 비교한다. 주소·태그는 검색하지 않는다. 결과가 없으면 이름을 다시 확인하도록 안내한다. 초기 등록 가게는 예시 가게 1이며 새 가게 신청은 관리자 승인 후에만 검색·선택할 수 있다.

카드 선택은 가게 상세를 여는 대신 검색 화면을 닫고 선결제 후원 입력란에 가게 이름을 채운다.
