# 한턱 그룹장 신청 알림 화면 기획서

그룹장 계정의 홈에 있는 그룹 신청 알림 버튼으로 진입한다. 카드에는 그룹 이름, 신청자 이름·아이디, 자기소개, 승인하기를 표시한다. 빈 자기소개는 작성하지 않았다고 안내한다.

승인하면 그룹원으로 추가하고 대기 목록에서 제거한다. 다른 그룹장은 승인할 수 없고 중복 승인도 소속을 다시 만들지 않는다. 신청자는 같은 실행에서 다시 로그인하면 승인된 그룹을 선택할 수 있다.

## 확인용 계정

| 관리 그룹 | 아이디 | 비밀번호 |
| --- | --- | --- |
| 예시 그룹 1 | leader01 | welcome123! |
| 예시 그룹 2 | leader02 | welcome123! |
| 예시 그룹 3 | leader03 | welcome123! |

hantuck01로 예시 그룹 1에 신청한 뒤 로그아웃하고 leader01로 로그인해 승인한다. 다시 hantuck01로 로그인해 반영을 확인한다. 새로고침하면 초기화되므로 계정 전환에는 로그아웃·로그인을 이용한다.
