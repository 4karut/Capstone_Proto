# 한턱 후원 감사 메시지 작성·완료 화면 기획서

이용자가 결제를 승인한 직후 진입한다. 마이페이지의 완료한 이용 내역에서도 다시 열 수 있다.

사용 완료 제목과 영수증에 사용 금액·가게·그룹·이용자·사용 후 잔액·사용시각을 표시한다. 아래에는 선택 입력임을 안내한다.

| 구성 | 조건 |
| --- | --- |
| 후원 감사 메시지 | 선택, 최대 500자, 보이는 문자 단위로 계산 |
| 사진 첨부 | 선택, 기기 파일 선택 창에서 JPG·PNG·WebP 1장, 최대 5MB |
| 사진 미리보기·바꾸기·삭제 | 선택 취소 시 이전 사진 유지, 읽기 실패 시 안내 |
| 후원 메시지 보내기 | 메시지 또는 사진 중 하나 이상 있으면 전송 |
| 건너뛰고 홈으로 | 감사 메시지를 보내지 않고 홈 복귀 |

선택한 실제 사진 파일을 읽어 형식·크기·읽기 가능 여부를 확인한다. 새 이미지를 생성하지 않는다. 본문은 앞뒤 공백을 제거하고 저장하며 공백만 있고 사진도 없으면 입력을 안내한다.

메시지와 사진은 해당 선결제를 후원한 계정에 연결한다. 후원자의 기존 사용 완료 알림에 함께 표시하고 받은 감사 메시지 목록에도 추가한다. 가게용 사용 알림에는 감사 본문·사진을 표시하지 않는다.

전송 후 감사 메시지를 보냈어요 제목, 전송 내용과 확인 버튼을 보여준다. 확인은 홈으로 돌아간다. 한 사용 건에 한 번만 보낼 수 있으며 중복 클릭으로 알림을 늘리지 않는다. 건너뛰기·뒤로가기와 무관하게 이미 완료한 사용·차감·사용 알림은 유지한다.

가게가 해당 결제를 취소하면 이 화면도 취소된 결제 내역으로 바뀐다. 작성 화면을 열어둔 상태에서도 새 메시지·사진 전송은 막는다. 이전에 보낸 메시지와 사진은 삭제하지 않고 취소 표시·복구 정보와 함께 보존한다.

사진과 메시지는 현재 앱 메모리에만 저장한다. 실제 사진 서버 업로드와 외부 메시지 전송은 연결하지 않으며 새로고침하면 초기화된다.
