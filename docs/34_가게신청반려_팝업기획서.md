# 한턱 가게 신청 반려 팝업 기획서

관리자가 심사 대기 중인 가게 신청 상세에서 반려하기를 누르면 연다. 승인하기와 구분된 테두리 버튼을 사용한다.

| 구성 | 동작 |
| --- | --- |
| 가게 신청 반려 제목 | 심사 결과 입력임을 표시 |
| 안내 | 신청자가 수정할 내용을 이해할 수 있도록 사유 작성 안내 |
| 반려 사유 입력 | 필수, 최대 300자, 입력 글자 수 표시 |
| 취소 | 입력만 폐기하고 심사 대기 유지 |
| 반려 확정 | 검증 후 반려 처리하고 심사 대기 목록으로 복귀 |

공백·줄바꿈만 있는 사유는 허용하지 않는다. 앞뒤 공백은 저장 시 제거한다. 글자 수는 이모지 조합 등을 포함한 사용자에게 보이는 문자 단위로 계산한다. 300자를 초과할 수 없으며 오류가 있으면 팝업을 유지하고 안내한다.

반려하면 해당 차수에 사유와 심사일시를 기록한다. 대기 목록과 건수에서 제외하고 신청자 마이페이지에 반려 상태·사유·정보 수정 후 재신청 버튼을 표시한다. 반려는 가게를 등록하거나 관리 권한을 부여하지 않는다. 실제 푸시 대신 앱 내 상태로 전달한다.

관리자만 반려할 수 있다. 이미 반려·승인된 차수에는 심사 결과를 다시 적용할 수 없다. 재신청이 접수되면 새 차수를 심사하며 이전 차수의 반려 결과는 보존한다.
