# 한턱 마이페이지 화면 기획서

하단 고정 바의 사람 모양 마이페이지 아이콘으로 진입한다. 홈·가게 찾기·즐겨찾기·마이페이지 네 항목을 사용한다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 마이페이지 제목 | 현재 화면 표시 |
| 2 | 기본 프로필과 이름 | 왼쪽 회색 바탕의 사람 실루엣, 오른쪽 가입자 이름 |
| 3 | 이메일과 전화번호 | 이름 아래 로그인 계정 정보 표시 |
| 4 | 계정 설정 | 가입 정보 확인과 로그아웃 화면 |
| 5 | 가게 신청하기 | 가게 신청 화면 |
| 6 | 가게 관리 | 승인된 본인 소유 가게가 있을 때만 표시 |
| 7 | 가게 신청 심사 | 관리자 계정에만 대기 건수와 함께 표시 |
| 8 | 내 가게 신청 내역 | 가게별 최신 차수의 이름·주소·차수·심사 대기/반려/승인 완료 표시 |

본인 승인 가게가 하나면 바로 관리 화면으로 이동한다. 둘 이상이면 관리할 가게 선택 화면으로 이동한다. 심사 대기 중에는 가게 관리 권한을 부여하지 않는다. 승인과 메뉴·사진 변경은 같은 실행 중 계정 전환 후에도 유지한다. 새로고침·재시작하면 초기화된다.

반려 건은 사유를 전부 표시하고 정보 수정 후 재신청 버튼을 제공한다. 재신청을 제출하면 카드가 새 차수의 심사 대기로 바뀐다. 모든 상태에서 신청 정보·이력 보기로 차수별 제출 정보와 반려 사유를 확인할 수 있다. 한 신청의 이전 차수를 별도 가게 카드로 중복 나열하지 않는다.

선결제 이용 내역·결제 확인 버튼에서 본인의 QR과 승인 요청을 다시 열 수 있다. 선결제 사용 알림은 본인이 후원한 선결제의 사용 소식을 제공한다. 받은 감사 메시지 보기 버튼은 본인에게 도착한 감사 메시지와 기기 첨부 사진을 모아 보여주고 받은 건수를 표시한다.

프로필 사진 수정과 개인정보 변경은 이번 범위에 포함하지 않는다. 프로필에는 기본 사람 아이콘을 사용하며 가게·그룹 사진은 기존 자산을 재사용한다. 감사 사진은 별도로 기기에서 첨부할 수 있다.
