# 한턱 소속 그룹 리스트 화면 기획서

홈 드롭다운 옆 정사각형 버튼이 여는 화면이다. 화면 제목은 소속 그룹 리스트다.

## 표시 대상과 카드

현재 로그인한 사용자가 가입한 모든 그룹만 표시한다. 승인 대기나 즐겨찾기만 지정한 그룹은 제외한다. 소속이 없으면 소속된 그룹이 없어요와 그룹 찾기 버튼을 표시한다.

그룹 카드에는 이름, 우측 썸네일 사진, 한 줄 소개, 카테고리·코드·태그를 표시한다. 즐겨찾기인 소속 그룹은 이름 옆에 빨간 하트를 표시한다.

카드를 누르면 해당 소속 그룹 상세로 이동한다. 상세에서 돌아오면 리스트의 즐겨찾기 표시도 갱신된다. 뒤로가기는 홈으로 돌아간다.
