# 한턱 가게 선결제 관리 화면 기획서

본인 가게 관리 상단 오른쪽 선결제 관리에서 진입한다. 상단에는 뒤로가기·선결제 관리 제목과 선택한 가게 이름을 표시한다.

같은 가게의 선결제를 그룹별 카드 하나로 묶는다. 카드에는 그룹 이름, 누적 선결제 총액, 남은 선결제 합계, 후원 건수와 현재 사용 가능한 금액을 표시한다. 카드를 누르면 해당 가게·그룹의 개별 선결제 상세로 이동한다.

가게 주인의 그룹 가입 여부와 관계없이 본인 가게의 내역을 확인한다. 다른 가게 내역은 포함하지 않는다. 일반 그룹원의 사용 가능 잔액 조회와 별도의 소유자 권한을 검사한다.

기간 종료·전액 사용 내역도 관리 기록에 남기고 현재 사용 가능 금액에는 포함하지 않는다. 내역이 없으면 빈 상태를 표시한다. 선결제 도착·이용자 결제 승인·사장님의 완료 결제 취소 시 목록을 갱신한다. 승인한 금액은 해당 후원의 사용액에 더하고, 취소한 금액은 사용액에서 빼 잔액에 복구한다. 원래 기한이 지났다면 복구 잔액도 현재 사용 가능 금액에 포함하지 않는다. 현금 환불은 연결하지 않는다.
