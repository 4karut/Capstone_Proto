# 한턱 가게 QR 결제 처리 화면 기획서

가게 소유자가 마이페이지 → 가게 관리 → QR 결제 처리에서 진입한다. 여러 가게를 소유하면 먼저 관리할 가게를 선택한다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 뒤로가기·QR 결제 처리·가게 이름 | 결제를 처리하는 가게 확인 |
| 2 | 이용 코드 입력 | 이용자가 제시한 6자리 코드 입력 |
| 3 | 선결제 확인 | 본인 가게의 유효한 요청 조회 |
| 4 | 그룹·이용자 이름·상태·잔액 | 선택된 선결제 확인 |
| 5 | 실제 메뉴 이용 금액 | 사장님이 1원 이상 정수로 입력 |
| 6 | 이용자에게 결제 확인 요청 | 입력 금액을 이용자에게 전달 |

다른 가게의 코드·타인 가게 관리·취소·만료·완료 코드는 처리할 수 없다. 잔액을 초과한 금액과 잘못된 값은 요청하지 않는다.

요청 후 금액과 이용자 승인 대기 안내를 표시한다. 이 단계에서는 차감하지 않는다. 이용자가 QR 화면 또는 마이페이지에서 승인하면 사용 완료로 바뀐다. 사장님이 이미 요청한 금액을 덮어쓰지 않는다. 잘못 요청했다면 이용자가 취소하고 새 QR로 다시 진행한다.

사용 완료된 결제의 정정은 가게 관리 → 선결제 사용 알림 → 결제 취소에서 진행한다. 코드 입력으로 완료한 결제를 다시 승인하거나 취소된 코드를 재사용하지 않는다. 현재 조회 중인 결제가 취소되면 취소 상태와 잔액 복구 안내를 표시한다.

현재 카메라 촬영·스캐너·외부 결제망은 연결하지 않는다. 프로토타입에서는 같은 앱에서 로그아웃·로그인하여 사장님과 이용자를 번갈아 체험한다.
