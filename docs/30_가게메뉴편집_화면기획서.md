# 한턱 메뉴 추가·수정 화면 기획서

가게 관리의 메뉴 추가 또는 특정 메뉴의 수정에서 진입한다. 상단에는 뒤로가기·메뉴 추가/메뉴 수정 제목과 가게 이름을 표시한다. 수정 시 기존 값을 채운다.

| 입력 | 필수 | 조건 |
| --- | --- | --- |
| 메뉴 이름 | 필수 | 1~50자, 같은 가게에서 공백 제외 같은 이름 중복 불가 |
| 가격 | 필수 | 1원 이상의 정수, 웹에서 정확히 처리 가능한 범위 |
| 메뉴 설명 | 선택 | 150자 이내 |
| 대표 메뉴 | 선택 | 스위치로 설정 |

저장하기를 누르면 입력을 검증하고 본인 가게에만 추가 또는 변경한다. 성공하면 관리 화면으로 돌아가며 공개 가게 메뉴에도 반영된다. 잘못된 값은 입력 오류를 표시하고, 중복 메뉴명은 안내한다. 뒤로가기는 저장하지 않고 복귀한다.
