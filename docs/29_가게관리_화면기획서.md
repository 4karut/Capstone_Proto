# 한턱 가게 관리 화면 기획서

마이페이지에서 본인 소유 승인 가게로 진입한다. 가게가 여러 개면 먼저 선택한다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 뒤로가기·가게 관리 | 마이페이지 또는 가게 선택으로 복귀 |
| 2 | 상단 오른쪽 선결제 관리 | 선택한 가게의 그룹별 내역 |
| 3 | 썸네일과 썸네일 변경 | 기존 사진 3개 중 선택하는 팝업 |
| 4 | 가게 이름·카테고리·주소 | 현재 가게 정보 확인 |
| 5 | QR 결제 처리·선결제 사용 알림·선결제 후원 알림 | 이용 코드와 금액 요청, 완료한 사용의 취소·잔액 복구, 도착한 후원 구분 |
| 6 | 가게 미리보기 | 사용자에게 공개되는 가게 상세 |
| 7 | 판매 메뉴 관리 | 이름·가격·설명·대표 메뉴 표시, 수정·삭제 |
| 8 | 메뉴 추가 | 메뉴 입력 화면 |

썸네일 팝업은 따뜻한 식사·캠퍼스·산책길 사진과 현재 선택 표시를 제공한다. 사진을 고르면 즉시 반영한다. 새 사진 생성과 기기 업로드는 하지 않는다.

메뉴 삭제는 확인 팝업을 거쳐 진행한다. 메뉴가 없으면 등록 안내를 표시한다. 사진·메뉴 변경은 가게 검색·즐겨찾기·상세·후원 선택에서도 최신 정보로 보인다. 소유자가 아닌 계정은 변경할 수 없다.

현재 가게명·사업자 정보·주소 수정, 운영 시간·품절·실제 주문·정산 기능은 범위에 포함하지 않는다.
