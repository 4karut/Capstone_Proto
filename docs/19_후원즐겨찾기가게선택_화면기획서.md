# 한턱 후원 즐겨찾기 가게 선택 화면 기획서

후원용 가게 검색창 옆의 하트 정사각형 버튼으로 진입한다. 현재 계정이 즐겨찾기한 가게만 표시한다.

상단에는 뒤로가기와 즐겨찾기 가게 제목을 두고, 아래에는 선택 안내와 가게 카드를 배치한다. 카드에는 이름·주소·기존 사진을 표시한다. 가게를 누르면 선택 화면과 검색 화면을 닫고 선결제 후원의 가게 입력란을 채운다. 금액과 기한은 유지한다.

즐겨찾기가 없으면 빈 상태와 가게 검색으로 돌아가기 버튼을 표시한다. 뒤로 가기는 선택값을 변경하지 않는다. 일반 즐겨찾기 화면과 같은 계정별 저장 목록을 사용하지만 이 화면에서 카드를 누르는 목적은 후원할 가게 선택이다.
