# 한턱 가게 상세 화면 기획서

가게 찾기, 즐겨찾기 가게, 홈과 소속 그룹 상세의 선결제 가게 카드를 누르면 같은 화면으로 진입한다. [배달의민족 공식 앱 소개와 스크린샷](https://apps.apple.com/kr/app/id378084485)을 시각 참고 자료로 확인하고, 대표 사진·가게 정보·판매 메뉴를 순서대로 읽는 배치를 구성했다. 한턱의 기존 색상과 글꼴을 사용한다.

## 화면 구성

| 순서 | 구성 |
| --- | --- |
| 1 | 뒤로가기, 가게 상세 제목, 즐겨찾기 하트 |
| 2 | 가게 대표 사진 |
| 3 | 가게 이름과 한 줄 소개 |
| 4 | 가게 태그와 주소 |
| 5 | 이용 가능한 선결제 합계와 기한별 선결제 카드, 각 그룹·잔액·사용 기한 |
| 6 | 판매 메뉴 수, 메뉴 이름·설명·가격과 대표 메뉴 표시 |
| 7 | 홈·가게 찾기·즐겨찾기·마이페이지 하단 고정 바 |

처음 하트는 테두리로 표시한다. 누르면 빨간 하트로 바뀌고 해당 계정의 즐겨찾기 가게에 추가한다. 다시 누르면 해제한다. 목록과 상세의 상태는 즉시 함께 갱신한다.

## 선결제별 잔액과 기한

선결제가 있으면 총 잔액과 건수를 표시하고, 기한이 빠른 순서로 건별 카드를 나열한다. 각 카드에 그룹 이름, 선결제 순번, 남은 금액, 총액·사용액, 사용 기한·남은 일수와 이용 기간을 표시한다. 같은 기한의 후원도 별도 내역을 유지한다.

홈 또는 소속 그룹 상세에서 진입하면 선택한 그룹의 선결제만 표시한다. 가게 찾기나 즐겨찾기에서 진입하면 현재 사용자가 가입한 모든 그룹의 이용 가능한 선결제를 표시하고 각 카드에 그룹을 명시한다. 비소속 그룹의 내역은 보여주지 않는다.

목록에서 합산하더라도 실제 선결제 데이터와 사용 기한은 건별로 보존한다. 시작 전·만료·잔액 0인 내역은 기존 기준에 따라 현재 사용 가능한 합계와 목록에서 제외한다.

소속 그룹이 없거나 선결제가 만료되어도 가게 찾기에서 상세를 열고 즐겨찾기할 수 있다. 저장한 가게도 즐겨찾기에 남는다. 이 경우 상세에서 이용 가능한 선결제가 없다는 안내와 가게 정보·메뉴를 표시한다. 선결제 금액은 그룹이 함께 쓰는 잔액이며 개인에게 지급한 금액으로 표시하지 않는다.

## 예시 가게 1

| 정보 | 값 |
| --- | --- |
| 가게 ID | example-store-1 |
| 주소 | 서울특별시 마포구 나눔로 12, 1층 (예시 주소) |
| 소개 | 정성껏 차린 한 끼로 따뜻한 마음을 나눠요. |
| 태그 | 한식, 든든한 한 끼, 함께하는 식사 |
| 사진 | 기존 group-team.png 재사용 |
| 대표 메뉴 | 따뜻한 집밥 정식 9,000원 |
| 메뉴 | 제육볶음 한 상 10,000원, 채소 비빔밥 8,000원 |
| 그룹 선결제 | 예시 그룹 3, 남은 65,000원, 2026.11.27까지 |

주소·메뉴·가격은 예시 데이터다. 새로운 이미지는 생성하지 않는다. 선결제 카드를 누르면 선택 표시와 선결제 이용 버튼이 나타나고 QR 화면으로 이동한다. 사장님이 금액을 요청하고 이용자가 승인하면 선택한 선결제에서만 잔액을 차감한다. 주문·장바구니와 외부 결제망은 연결하지 않는다.
