# 한턱 선결제 이용 내역 화면 기획서

마이페이지의 선결제 이용 내역·결제 확인을 누른다. 계정 전환이나 화면 이탈 후에도 본인의 QR·결제 요청을 다시 열 수 있는 화면이다.

가게 이름, 그룹, 진행 상태와 요청 금액을 최신 요청부터 카드로 보여준다. 카드를 누르면 해당 QR·승인 화면을 연다. 가게 확인 대기·승인 대기·사용 완료·취소·코드 만료를 구분한다. 기록이 없으면 이용 가능한 가게에서 선결제를 선택하도록 안내한다.

완료된 요청에서도 사용 영수증을 확인하고 감사 메시지를 작성할 수 있다. 작성하지 않고 건너뛴 메시지도 이후에 한 번 보낼 수 있다. 이미 보낸 메시지는 확인만 하며 수정·재전송하지 않는다.

가게에서 사용 완료 건을 취소하면 해당 카드에 결제 취소와 원래 사용 금액을 표시한다. 상세에서 취소·복구 내역을 확인하며 QR과 승인 버튼은 다시 표시하지 않는다. 취소된 결제에는 새 감사를 작성할 수 없으며 기존에 보낸 내용만 확인할 수 있다.

본인 기록만 표시한다. 실행 중 메모리에 유지하며 새로고침·앱 재시작 시 초기화된다.
