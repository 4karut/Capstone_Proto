# 한턱 가게 신청 정보 화면 기획서

관리자가 심사 대기 카드를 눌러 진입한다. 상단 뒤로가기·가게 신청 정보 제목 아래 가게 이름을 굵게 표시한다. 사업자등록번호·주소·카테고리·가게 전화번호·선택 소개·신청자 이름과 ID를 차례로 표시한다.

하단 승인하기를 누르면 가게를 등록하고 신청자 계정에 소유권을 연결한다. 대기 목록으로 복귀하며 승인 결과를 안내한다. 같은 신청을 다시 승인해도 가게를 중복 생성하지 않는다.

승인 즉시 전체 가게 검색과 선결제 후원 선택에 표시한다. 기존 사진을 기본 썸네일로 지정하고 메뉴가 없으면 준비 중으로 표시한다. 신청자는 마이페이지에서 가게 관리를 할 수 있다.

상세에 현재 차수를 표시한다. 재신청이면 이전 신청·반려 이력 확인 버튼으로 차수별 제출 정보와 사유를 확인할 수 있다. 현재 화면의 정보는 최신 수정본이며 이전 제출 내용은 덮어쓰지 않는다.

승인하기 아래에는 반려하기 버튼을 둔다. 누르면 필수 반려 사유를 최대 300자로 입력하는 팝업을 연다. 반려 확정 후 대기 목록으로 돌아가고 신청자에게 마이페이지 상태로 전달한다. 반려된 차수를 바로 승인할 수 없으며 신청자가 새 차수로 재접수해야 한다. 재신청도 같은 승인·반려 절차를 적용한다.

프로토타입에서는 관리자가 입력 내용을 확인하며 실제 사업자·영업 신고 진위 확인은 하지 않는다고 안내한다. 실제 운영을 위한 심사 기준은 별도로 설계해야 한다.
