# 한턱 가게 신청 완료 화면 기획서

유효한 정보를 제출하면 신청 입력 화면이 완료 화면으로 전환된다. 체크 아이콘, 가게 신청이 완료됐다는 제목, 신청 가게 이름, 관리자 승인 후 검색과 선결제 후원에 공개된다는 안내를 표시한다.

하단 확인을 누르면 마이페이지로 돌아간다. 내 가게 신청 내역에는 심사 대기가 표시된다. 이 화면에 머무르거나 확인을 여러 번 눌러도 신청 내역을 추가 생성하지 않는다. 실제 승인과 공개는 관리자 심사에서 수행한다.

반려 후 수정본을 제출한 경우 제목을 가게 재신청이 완료됐어요로 표시하고 같은 확인 동작을 제공한다. 마이페이지에는 다음 차수의 심사 대기 상태를 표시하며, 이전 정보와 반려 사유는 이력 화면에 남긴다.
