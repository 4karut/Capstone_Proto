# 한턱 가게 선결제 알림 화면 기획서

마이페이지 → 가게 관리 → 선결제 알림에서 진입한다. 선택한 본인 가게의 내역만 보여주며 상단에 가게 이름을 표시한다. 기존 홈의 가게 선결제 알림에서는 소유 가게 전체 알림을 확인할 수 있다. 예시 가게 1의 계정은 store01 / welcome123!이다. 새 가게는 신청 후 관리자 승인을 받으면 신청자 계정으로 관리한다.

상단에는 뒤로가기·가게 선결제 알림 제목과 도착한 후원 건수를 표시한다. 아래에는 해당 가게로 결제된 선결제 후원을 최신순으로 나열한다. 카드에는 금액·후원 그룹·후원자·가게·사용 기한·결제일을 표시한다.

그룹으로 직접 전달한 금액 후원은 가게에 표시하지 않는다. 로그인한 사용자가 관리하는 가게의 선결제 알림만 제공하며, 내역이 없으면 빈 상태를 보여준다. 확인을 위한 추가 승인 단계는 두지 않는다.

알림은 프로토타입 앱 안의 기록이다. 실제 이메일·문자·모바일 푸시는 전송하지 않는다. 다른 계정으로 확인할 때는 새로고침 대신 로그아웃·로그인을 사용한다.
