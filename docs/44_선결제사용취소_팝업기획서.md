# 한턱 선결제 사용 완료 후 취소 팝업 기획서

가게 소유자가 마이페이지 → 가게 관리 → 선결제 사용 알림에서 사용 완료된 내역의 결제 취소를 누르면 연다. 결제 완료 전 이용자가 하는 이용 요청 취소와 구분한다.

| 구성 | 동작 |
| --- | --- |
| 선결제 사용 취소 제목 | 완료된 사용 건 취소임을 표시 |
| 가게·그룹·이용자 | 취소 대상을 확인 |
| 복구 금액 | 해당 결제의 사용 금액 전액 표시, 금액 수정 불가 |
| 안내 | 원래 선결제 건에 복구하고 사용 기한을 유지함을 안내 |
| 취소 사유 | 선택, 최대 300자, 보이는 문자 단위로 제한 |
| 돌아가기 | 변경 없이 팝업 닫기 |
| 결제 취소 확정 | 취소 기록과 잔액 복구를 한 번 적용 |

취소 가능 기간은 프로토타입에서 제한하지 않는다. 사유를 비워 두거나 공백만 입력해도 취소할 수 있으며 앞뒤 공백을 제거해 기록한다. 확정 전에는 잔액을 바꾸지 않는다.

선택한 본인 가게의 완료된 결제만 취소할 수 있다. 이용자·후원자·관리자 계정은 가게 소유 권한 없이 취소하지 못한다. 같은 사장님이 여러 가게를 운영해도 선택한 가게의 내역만 처리한다.

결제가 실제 사용한 선결제 건의 사용액에서 해당 금액을 빼고 현재 잔액에 더한다. 다른 사용자가 이후에 사용한 금액이나 같은 가게의 다른 후원 건은 바꾸지 않는다. 총 선결제액·그룹·가게·후원자·시작일·종료일을 유지한다. 같은 결제를 다시 취소해도 중복 복구하지 않는다.

원래 기한이 이미 지났어도 잔액 복구와 취소 기록은 남긴다. 사용 기한은 연장하지 않으므로 만료 잔액은 이용 가능 목록에 나타나지 않는다. 가게 관리의 기존 내역에서는 잔액을 확인할 수 있다. 전액 사용했던 건은 기한이 남아 있다면 복구 후 다시 이용 가능해진다.

완료 후 가게·이용자·후원자의 기존 내역에 결제 취소 상태, 복구 금액, 취소 후 잔액, 원래 기한, 취소 사유·시각을 표시한다. 이전 결제 금액과 당시 잔액·시각도 보존한다. 기존 감사 메시지와 사진은 취소 표시와 함께 남기고 취소된 결제의 새 감사 전송은 막는다.

취소한 결제의 QR은 재사용하거나 다시 승인할 수 없다. 다시 이용하려면 선결제를 선택하고 새 QR을 발급한다. 현재는 전액 취소를 제공하며 부분 취소·취소 철회와 실제 현금 환불은 연결하지 않는다. 기록은 실행 중 메모리에 유지하며 새로고침 시 초기화된다.
