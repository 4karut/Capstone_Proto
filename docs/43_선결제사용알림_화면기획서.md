# 한턱 선결제 사용 알림 화면 기획서

후원자는 마이페이지의 선결제 사용 알림에서, 가게 소유자는 해당 가게 관리의 선결제 사용 알림에서 진입한다. 기존 선결제 후원 도착 알림과 별도 버튼·목록으로 구분한다.

이용자 결제 승인이 성공한 경우에만 사용 완료 알림을 생성한다. QR 발급, 사장님 금액 요청, 이용 요청 취소·만료에는 사용 완료 알림을 만들지 않는다.

카드에는 사용 금액, 가게, 그룹·이용자, 사용 후 해당 선결제 잔액과 사용시각을 표시한다. 후원자는 자기 후원의 사용 내역을 보고 감사 메시지·사진이 전송되면 같은 카드에서 함께 확인한다. 가게는 선택한 본인 가게의 사용 내역만 보며 감사 본문·사진은 표시하지 않는다.

가게 소유자는 본인 가게의 취소되지 않은 완료 내역에서 결제 취소를 누른다. 선택 사유를 최대 300자로 입력하고 확정하면 사용 금액 전액을 원래 선결제에 한 번 복구한다. 취소된 내역에는 취소 버튼을 제거하고 취소 표시·복구 금액·잔액·원래 기한·사유·시각을 보여준다. 원래 기한이 지난 잔액은 복구 후에도 사용할 수 없다는 안내를 표시한다. 후원자도 기존 알림 카드에서 취소 상태를 확인한다.

상단 건수는 완료·취소를 포함한 사용 내역 건수다. 금액·후원자·기간이 다른 후원은 서로 섞지 않는다. 동일 결제 승인·취소·감사 전송을 반복해도 사용 건과 알림을 중복 생성하지 않는다. 알림이 없으면 빈 상태를 표시한다.

현재 알림은 앱 내 기록이며 푸시·문자·이메일을 발송하지 않는다. 같은 실행 중 로그아웃·로그인으로 계정을 전환해 확인하고 새로고침은 피한다.
