# 한턱 가게 신청 화면 기획서

마이페이지의 가게 신청하기에서 진입한다. 상단에는 뒤로가기·제목과 정보 입력 → 관리자 심사 → 승인 후 공개 절차를 표시한다.

| 입력 | 필수 | 조건 |
| --- | --- | --- |
| 가게 이름 | 필수 | 공백 제외 1~50자 |
| 사업자등록번호 | 필수 | 하이픈 제외 숫자 10자리, 프로토타입에서는 형식만 확인 |
| 가게 주소 | 필수 | 도로명·상세 주소 직접 입력, 1~150자 |
| 카테고리 | 필수 | 한식·중식·일식·양식·분식·카페·디저트·기타 중 하나 |
| 가게 전화번호 | 필수 | 계정 번호를 기본 입력하고 수정 가능, 0으로 시작하는 9~11자리 |
| 한 줄 소개 | 선택 | 100자 이내 |

하단에 신청자 이름과 이 계정이 가게 관리자가 된다는 안내, 신청하기 버튼을 표시한다. 오류가 있으면 해당 입력을 안내하며 신청하지 않는다. 같은 사업자등록번호와 같은 주소로 대기 또는 승인 가게가 있으면 중복 신청을 막는다. 여러 지점은 별도 주소로 신청할 수 있다. 이는 프로토타입의 중복 방지 기준이다.

신청하기를 누르면 대기 내역을 한 번 생성하고 신청 완료 화면으로 전환한다. 승인 전에는 가게 찾기·즐겨찾기 가게 목록·선결제 후원 선택 목록에 공개하지 않는다. 신청자가 임의로 승인할 수 없으며 별도 관리자 계정으로 심사한다.

배민 공식 입점 안내는 사업자등록증·영업신고증, 메뉴, 카테고리, 서비스 선택, 정산계좌, 가게 정보 확인과 심사 절차를 안내한다. [배민 신규 입점 및 가입](https://ceo.baemin.com/guide/4024). 요기요의 기존 공식 소개자료도 사업자·음식점 정보를 입력해 신청하고 전화 계약을 거치는 절차를 안내한다. 해당 자료는 과거 자료이므로 현재 세부 조건으로 단정하지 않는다. [요기요 공식 소개자료](https://rev-static.yogiyo.co.kr/owners/YGY_INFO_%28OD%29OL.pdf).

한턱 프로토타입에는 기본 정보 제출 → 별도 관리자 심사 → 승인 후 공개 구조를 적용한다. 반려 시 관리자가 필수 사유를 최대 300자로 입력한다. 신청자는 마이페이지에서 사유를 확인하고 기존 정보를 수정해 새 차수로 재접수한다. 기존 제출 내용과 사유는 보존한다. 같은 가게의 반려 건이 이미 있으면 새 가게 신청 대신 해당 건의 재신청을 사용한다.

실제 서류 업로드, 사업자 진위 조회, 계약·정산계좌, 주소 조회 서비스는 연결하지 않는다. 운영 서비스 전환 시 서류 확인·심사 기준은 추가로 정해야 한다.
