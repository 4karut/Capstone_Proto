# 한턱 후원 결제 완료 화면 기획서

금액 후원 또는 선결제 후원에서 확인을 누르면 바로 진입한다. 외부 결제창과 실제 청구는 연결하지 않는다.

| 순서 | 구성 |
| --- | --- |
| 1 | 완료 아이콘과 결제가 완료됐습니다 문구 |
| 2 | 후원 방식과 금액 |
| 3 | 후원 대상 그룹·후원자·결제일 |
| 4 | 선결제인 경우에만 가게와 사용 기한 |
| 5 | 수신자의 알림함에 내역을 남겼다는 안내 |
| 6 | 실제 청구가 없는 프로토타입 완료 표시 |
| 7 | 확인 버튼 |

확인을 누르면 이전 후원 입력·가게 검색·그룹 상세를 닫고 홈 탭으로 돌아간다. 완료 화면에는 뒤로가기 버튼을 두지 않으며 기기 뒤로가기로 결제 입력을 다시 열지 않는다. 같은 결제 요청은 한 번만 기록한다. 새 후원은 그룹 상세에서 다시 시작한다.

금액 후원은 그룹장에게만, 선결제 후원은 그룹장과 해당 가게 사장님에게 알림을 생성한다. 기록과 알림은 같은 앱 실행 중 유지하며 새로고침·재시작하면 초기화된다.
