# 한턱 받은 감사 메시지 화면 기획서

마이페이지의 받은 감사 메시지 보기 버튼으로 진입하며 버튼에 받은 건수를 표시한다.

상단 뒤로가기·받은 감사 메시지 제목 아래 도착한 감사 건수와 안내를 표시한다. 본인이 후원한 선결제의 이용자가 보낸 메시지·사진을 누적해서 확인한다.

카드에는 사용 금액, 가게, 그룹·이용자 이름, 사용 후 잔액, 사용시각, 감사 본문, 첨부 사진과 메시지 도착시각을 표시한다. 본문만 또는 사진만 보낸 경우에도 해당 내용을 보여준다. 사진의 비율을 유지하고 전체 내용을 확인할 수 있게 한다.

메시지를 건너뛴 사용 건은 이 목록에 포함하지 않으며 선결제 사용 알림에서 조회한다. 받은 내용이 없으면 빈 상태를 표시한다. 다른 후원자의 감사 내용은 볼 수 없다. 그룹 가입 여부나 가게 소유 여부와 관계없이 후원자 계정을 기준으로 제공한다.

사용 완료된 결제가 이후 취소되어도 기존 감사 메시지와 사진은 보존한다. 같은 카드에 선결제 사용 취소 표시와 복구 금액·잔액·원래 기한·취소 사유·시각을 추가해 과거 사용 완료와 구분한다.

현재 답장·수정·삭제·외부 공유는 범위에 포함하지 않는다. 실행 중 기록이며 새로고침·재시작 시 초기화된다.
