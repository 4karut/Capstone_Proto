# 한턱 로그인 화면 기획서 초안

앱 실행 시 처음 표시한다. 기존 사용자는 아이디와 비밀번호로 홈에 진입하고, 처음 이용하는 사람은 회원가입으로 이동한다.

## 화면 정보와 구성

| 항목 | 내용 |
| --- | --- |
| 화면 식별자 | AUTH-02 |
| 진입 | 앱 실행, 로그아웃, 회원가입 완료 |
| 입력 | 아이디, 비밀번호 |
| 주요 버튼 | 로그인 |
| 보조 버튼 | 회원가입, 데모 계정 채우기, 비밀번호 보기 |
| 성공 시 | 홈으로 이동 |

브랜드와 서비스 소개, 아이디와 비밀번호, 로그인 버튼, 회원가입 안내, 체험용 계정 안내 순서로 배치한다. 회원가입 완료로 돌아온 경우 입력란 위에 가입 완료 안내를 표시한다.

## 입력과 로그인

아이디와 비밀번호는 필수다. 빈 항목은 해당 입력란 아래에 안내한다. 아이디 앞뒤 공백과 영문 대소문자는 구분하지 않는다. 비밀번호는 입력한 값을 그대로 비교한다.

등록되지 않은 아이디 또는 잘못된 비밀번호는 아이디 또는 비밀번호를 확인해 주세요라고 동일하게 안내한다. 입력 내용을 수정하면 해당 안내를 지운다. 비밀번호는 기본으로 숨기고 보기 버튼으로 전환한다.

로그인 성공 시 로그인 화면을 홈으로 교체한다. 홈에서 뒤로가기로 이전 로그인 화면에 돌아가지 않게 한다.

## 회원가입 이동

회원가입 버튼은 회원가입 화면을 연다. 가입 도중 로그인으로 버튼이나 뒤로가기를 누르면 계정을 등록하지 않고 돌아온다.

가입이 완료되면 먼저 본인 인증 완료 화면을 표시한다. 로그인 화면에는 새 아이디를 채우고 비밀번호는 비워 둔다. 로그인하러 가기로 돌아온 사용자는 가입 시 정한 비밀번호를 입력해 로그인한다.

## 체험용 계정

| 항목 | 값 |
| --- | --- |
| 아이디 | hantuck01 |
| 비밀번호 | welcome123! |
| 이름 | 한나눔 |

데모 계정 채우기 버튼은 입력란만 채운다. 이후 로그인 버튼을 눌러 홈으로 이동한다. 해당 값은 화면 검토용 가상 계정이다.

## 저장 범위

회원가입 계정은 앱이 실행되는 동안에만 유지한다. 브라우저 새로고침이나 앱 재시작 시 사라지고 체험용 계정만 다시 준비한다. 로그인 화면 하단에도 이 동작을 안내한다. 실제 인증 서버, 자동 로그인, 아이디·비밀번호 찾기는 후속 설계 대상이다.
