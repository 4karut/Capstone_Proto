# 한턱 후원 방식 선택 화면 기획서

그룹 상세의 후원하기를 누르면 진입한다. 가입 여부와 관계없이 검색이나 즐겨찾기로 찾은 그룹에 후원할 수 있다. 후원 자체로 그룹에 가입되지는 않는다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 뒤로가기와 후원하기 제목 | 이전 그룹 상세로 복귀 |
| 2 | 후원 대상 그룹 카드 | 이름, 카테고리·공개 코드와 기존 썸네일 표시 |
| 3 | 금액 후원 카드 | 금액 후원 입력 화면으로 이동 |
| 4 | 선결제 후원 카드 | 선결제 후원 입력 화면으로 이동 |
| 5 | 프로토타입 안내 | 실제 결제 없이 체험함을 안내 |

두 후원 방식은 화면을 나누어 입력한다. 대상 그룹은 진입한 그룹으로 고정한다. 기존 하단 고정 바를 유지한다.
