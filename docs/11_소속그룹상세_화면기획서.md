# 한턱 소속 그룹 상세 화면 기획서

소속 그룹 리스트의 카드를 누르면 진입한다. 검색에서 이미 가입한 그룹을 열어도 동일한 화면을 표시한다.

## 구성

| 순서 | 구성 |
| --- | --- |
| 1 | 뒤로가기, 소속 그룹 제목, 즐겨찾기 하트 |
| 2 | 왼쪽 굵은 이름과 대표 태그, 오른쪽 썸네일 |
| 3 | 이름 아래 한 줄 소개, 아래 카테고리와 나머지 태그 |
| 4 | 공개 그룹 코드와 가입 상태 |
| 5 | 후원하기 버튼 |
| 6 | 이용 가능한 선결제 가게 수와 가게 카드 |

이미 가입했으므로 그룹 신청 버튼은 표시하지 않는다. 후원하기는 금액 후원·선결제 후원 선택 화면으로 연결한다.

## 선결제 가게 카드

같은 그룹의 같은 가게는 선결제가 여러 건이어도 카드 하나로 묶는다. 카드에는 가게 이름, 사용 가능한 선결제 건수, 사용 금액 합계, 남은 금액 합계, 총 선결제와 합산 사용률을 표시한다. 홈의 선택 그룹과 같은 데이터를 사용한다.

한 건이면 기존처럼 사용 기한과 이용 기간을 표시한다. 여러 건이면 가장 빠른 사용 기한과 남은 일수를 표시하고 가게를 눌러 기한별 잔액을 확인하도록 안내한다. 전체 잔액이 가장 빠른 기한에 모두 만료되는 것으로 표시하지 않는다.

가게 카드를 누르면 해당 그룹으로 범위를 고정한 가게 상세를 연다. 상세에는 합계 잔액과 함께 각 선결제의 남은 금액·총액·사용액·사용 기한·이용 기간을 별도 카드로 표시한다. 기한이 같은 후원도 서로 다른 건으로 보존한다.

| 예시 정보 | 값 |
| --- | --- |
| 그룹 | 예시 그룹 3 |
| 가게 | 예시 가게 1 |
| 총 선결제 | 100,000원 |
| 사용 금액 | 35,000원 |
| 남은 선결제 | 65,000원 |
| 사용률 | 35% |
| 이용 기간 | 2026.10.28 ~ 2026.11.27 |
| 남은 기간 | 2026.10.28 기준 30일 |

남은 기간은 한국 날짜 기준으로 계산한다. 만료일 당일은 오늘까지로 표시한다. 기간이 시작되지 않았거나 끝난 선결제, 잔액이 없는 선결제는 이용 가능한 목록에서 제외한다.

예를 들어 초기 예시 가게 1의 잔액 65,000원에 100,000원을 추가로 후원하면 그룹 3 화면에는 가게 하나와 잔액 165,000원이 표시된다. 상세에서는 기존 65,000원·기한 2026.11.27과 새 100,000원·후원 시 지정한 기한을 따로 확인한다. 데이터 자체를 합치거나 기존 기한을 덮어쓰지 않는다.

해당 그룹의 소속이 있는 사람에게만 목록을 제공한다. 초기 예시 그룹 1·2에는 가게를 연결하지 않아 빈 상태로 표시하며 선결제 후원 완료 시 가게가 추가된다. 카드를 누르면 가게 상세에서 주소·소개·태그·메뉴를 확인하고 즐겨찾기할 수 있다. 실제 가게 이용·주문·거래는 후속 기획 대상이다.
