# 한턱 그룹 신청과 초대 팝업 기획서

그룹 신청은 잠금 상태에 따라 일반 신청 또는 초대 코드 팝업을 연다.

## 일반 신청과 완료

그룹 이름을 포함한 제목, 자기소개, 신청하기, 취소를 표시한다. 자기소개는 사용자가 선택 입력으로 확정했다. 비워 두어도 신청할 수 있고 최대 100자다. 현재 글자 수를 표시하며 한글과 이모지는 화면에 보이는 글자 단위로 센다.

신청하면 그룹장에게 전달할 이름·아이디·자기소개를 기록하고 승인 대기로 둔다. 중복 신청은 막는다. 제출 전 취소는 기록하지 않는다.

신청이 완료되었어요와 그룹장 알림 안내를 표시한다. 확인은 상세·검색을 닫고 홈으로 돌아간다. 승인 전까지 소속은 늘어나지 않고 홈에 승인 대기를 표시한다.

## 초대 코드 가입

잠긴 그룹은 자기소개 없이 숫자 6자리 초대 코드 팝업을 연다. 예시 그룹 3의 코드는 123456이다. 잘못된 코드는 오류를 표시하고 팝업을 유지한다.

맞으면 승인 없이 바로 그룹원이 된다. 가입 완료의 확인은 홈으로 이동하고 소속 드롭다운에 반영된다. 중복 가입은 막는다.

## 데모 범위와 다음 결정

알림은 앱 안에서 그룹장 계정이 보는 신청 알림이다. 실제 휴대폰 푸시·이메일·서버 전송은 수행하지 않는다. 상태는 실행 동안 유지하고 새로고침 시 초기화된다.

신청 취소·거절, 초대 코드 만료·교체·재사용 정책, 신청 잠금 관리 화면은 후속 기획 대상이다.
