# 한턱 가게 재신청 화면 기획서

마이페이지의 최신 반려 신청에서 정보 수정 후 재신청을 누른다. 상단에는 뒤로가기·가게 재신청 제목, 이전 반려 사유와 다음 신청 차수 안내를 표시한다.

최신 반려 차수의 가게 이름·사업자등록번호·주소·카테고리·가게 전화번호·소개를 모두 불러온다. 기존 신청과 동일한 필수 여부·길이·형식 검증을 적용하며 각 항목을 수정할 수 있다.

하단 다시 신청하기를 누르면 수정본을 새 차수의 심사 대기로 접수한다. 제출 정보는 별도 기록으로 저장하고 이전 차수와 연결한다. 이전 제출 내용과 반려 사유는 보존한다. 재신청 완료 화면의 확인을 누르면 마이페이지로 돌아간다.

마이페이지에는 해당 신청의 최신 차수 카드 하나와 상태를 표시한다. 이전 차수는 신청 정보·이력 보기에서 확인한다. 관리자 대기 목록에도 최신 접수 차수만 표시하고 재신청임을 안내한다.

뒤로가기는 수정 내용을 제출하지 않는다. 입력 오류나 다른 가게와의 사업자등록번호·주소 중복이 있으면 접수하지 않으며 기존 반려 건을 유지한다. 같은 신청의 이전 차수와 동일한 번호·주소는 중복으로 처리하지 않는다. 동일 가게의 반려 건이 이미 있다면 새 가게 신청 대신 해당 건의 재신청을 사용한다.

신청자만 최신 반려 차수를 재신청할 수 있다. 심사 대기·승인 완료 건, 이미 후속 차수가 있는 이전 반려 건, 타인 신청의 재제출은 막는다. 같은 차수를 두 번 제출해 병렬 심사가 생기지 않게 한다. 다시 반려되면 해당 차수에서 수정하여 다음 차수를 신청할 수 있다.

재신청했다고 가게를 공개하거나 관리 권한을 부여하지 않는다. 관리자 승인 후에만 수정본을 기준으로 가게 하나를 등록하고 검색·선결제 후원·가게 관리를 허용한다.
