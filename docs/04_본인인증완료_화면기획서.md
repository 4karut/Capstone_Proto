# 한턱 본인 인증 완료 화면 기획서 초안

회원가입의 입력 검사와 이메일 인증을 마친 사용자가 본인 인증하기를 누르면 바로 표시한다. 프로토타입의 본인 인증은 실제 인증기관 연결 없이 완료로 처리한다.

## 화면 정보

| 항목 | 내용 |
| --- | --- |
| 화면 식별자 | AUTH-03 |
| 진입 조건 | 아이디 중복 확인, 비밀번호 일치, 필수 정보 입력, 이메일 코드 인증 성공 |
| 제목 | 본인 인증이 완료되었어요 |
| 안내 | 사용자 이름을 포함한 가입 축하와 로그인 요청 |
| 데모 표시 | 데모 인증 완료, 실제 본인 인증은 진행되지 않았어요. |
| 주요 버튼 | 로그인하러 가기 |
| 다음 화면 | 로그인 |

## 이동 동작

화면 진입 시 데모 계정 등록이 완료된 상태다. 로그인하러 가기와 뒤로가기는 모두 로그인 화면으로 돌아간다. 가입한 아이디는 채워져 있고 비밀번호는 새로 입력한다. 이 화면에서 자동 로그인하지 않는다.

완료 화면에 재진입하는 버튼은 두지 않는다. 사용자는 새 계정으로 로그인하거나 다른 회원가입을 시작할 수 있다.
