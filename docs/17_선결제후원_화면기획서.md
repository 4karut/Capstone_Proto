# 한턱 선결제 후원 화면 기획서

후원 방식 선택에서 선결제 후원을 누르면 진입한다. 그룹이 이용할 가게와 금액, 사용 기한을 지정한다.

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 뒤로가기와 선결제 후원 제목 | 방식 선택으로 복귀 |
| 2 | 후원 대상 그룹 카드 | 이름·카테고리·코드·기존 썸네일 표시 |
| 3 | 선결제 가게 입력란 | 후원용 가게 검색 화면을 열고 선택 결과를 입력 |
| 4 | 결제 금액 입력란 | 1원 이상의 원 단위 금액 입력 |
| 5 | 선결제 사용 기한 | 직접 날짜 입력 또는 달력 선택 |
| 6 | 프로토타입 결제 안내와 확인 버튼 | 검증 후 즉시 결제 완료 화면으로 이동 |

세 항목 모두 필수다. 날짜는 YYYYMMDD, YYYY.MM.DD, YYYY-MM-DD 형식으로 입력할 수 있다. 실제 달력에 없는 날짜와 과거 날짜는 막는다. 사용자가 확정한 기준에 따라 오늘도 선택할 수 있으며 한국 시간으로 종료일 23:59까지 이용한다. 이용 시작일은 결제일이다.

가게 선택 화면에서 돌아와도 입력한 금액과 기한을 유지한다. 취소하면 기존 가게 선택을 유지하며, 선택한 가게는 직접 입력한 임의의 이름으로 바꿀 수 없다.

완료하면 해당 그룹·가게에 입력 금액을 새 선결제로 기록한다. 최초 사용액은 0원이다. 기존 선결제와는 후원 건별로 보존해 기한을 구분한다. 홈과 소속 그룹 상세에서는 같은 가게를 카드 하나로 묶고 합계 잔액과 건수를 표시한다. 해당 가게 상세에서 각 선결제의 잔액·기간을 확인한다. 가게 찾기에도 같은 가게를 한 번만 표시하고 가게 개수는 중복 없이 센다.

소속 그룹원은 새 선결제를 바로 확인할 수 있다. 후원자가 비회원이면 후원만으로 사용 권한이 생기지 않는다. 대상 그룹장과 가게 사장님의 알림함에 각각 후원 내역을 남긴다.
