# 한턱 금액 후원 화면 기획서

후원 방식 선택에서 금액 후원을 누르면 진입한다. 대상 그룹에 전달할 금액을 입력하고 확인을 누르면 프로토타입 결제가 완료된다.

| 순서 | 구성 |
| --- | --- |
| 1 | 뒤로가기와 금액 후원 제목 |
| 2 | 후원 대상 그룹의 이름·카테고리·공개 코드·썸네일 |
| 3 | 결제 금액 입력란과 원 표시 |
| 4 | 실제 청구가 없는 프로토타입 안내 |
| 5 | 확인 버튼 |

금액은 필수이며 1원 이상의 원 단위 정수로 입력한다. 비어 있거나 0인 금액은 오류를 표시하고 완료하지 않는다. 가게와 사용 기한은 입력하지 않는다.

확인 시 같은 요청이 중복 기록되지 않도록 처리한 후 결제 완료 화면으로 이동한다. 완료된 금액 후원은 대상 그룹장의 후원 알림함에 표시하며 가게에는 알림을 만들지 않는다. 금액 후원금의 출금·사용·정산 기능은 이번 화면 범위에 포함하지 않는다.

입력 중 뒤로 가거나 하단 바로 나가면 후원은 생성되지 않는다.
