# 한턱 가게 찾기 화면 기획서

하단 고정 바의 가게 찾기를 누르면 진입한다. 가입한 그룹과 관계없이 앱에 등록된 모든 가게를 둘러보고, 이름으로 찾아 즐겨찾기할 수 있는 화면이다. 소속 그룹이나 사용 가능한 선결제가 없는 사용자에게도 가게를 표시한다.

## 구성과 검색

| 순서 | 구성 | 동작 |
| --- | --- | --- |
| 1 | 가게 찾기 제목과 안내 | 그룹 가입 없이 둘러보고 즐겨찾기할 수 있음을 안내 |
| 2 | 가게 이름 검색란과 검색 버튼 | 버튼 또는 키보드 검색으로 실행 |
| 3 | 전체 가게 수 또는 검색 결과 수 | 현재 조건에 맞는 개수 표시 |
| 4 | 가게 카드 | 기존 사진, 이름, 한 줄 소개, 주소, 태그와 현재 계정의 선결제 이용 가능 여부 표시 |
| 5 | 하단 고정 바 | 홈·가게 찾기·별표 즐겨찾기·마이페이지로 이동 |

검색 대상은 가게 이름뿐이다. 공백을 제외한 부분 일치를 지원하며, 빈 검색은 등록된 전체 가게를 표시한다. 주소·태그·소개는 검색 대상에 포함하지 않는다. 검색어 옆 지우기는 입력과 검색 조건을 함께 초기화한다. 같은 가게는 한 번만 나열한다.

가게 카드를 누르면 가게 상세 화면을 연다. 상세 상단 하트로 저장하면 하단 별표의 즐겨찾기 가게 탭에서 다시 확인할 수 있다. 소속이나 선결제 이용 가능 여부는 가게 열기·즐겨찾기를 제한하지 않는다. 하단 바로 다른 항목에 이동하면 열린 상세를 닫고 해당 화면을 표시한다.

## 빈 상태

| 조건 | 표시 |
| --- | --- |
| 앱에 등록된 가게 자체가 없음 | 등록된 가게가 없다는 안내 |
| 등록 가게는 있으나 이름이 일치하지 않음 | 검색 결과가 없다는 안내 |

가게 탐색과 선결제 이용 권한은 별개다. 해당 사용자의 소속 그룹에 현재 사용할 수 있는 선결제가 있으면 이용 가능으로 표시한다. 소속이 없거나 선결제가 시작 전·기간 종료·잔액 0이면 가게는 계속 보여주고 현재 이용 가능한 선결제가 없다고 표시한다. 기간 판단에는 기존 한국 날짜 기준을 사용한다.

초기 등록 가게는 예시 가게 1이다. 마이페이지에서 신청한 가게는 관리자 승인 후에만 이 목록에 추가된다. 대기 중인 신청은 공개하지 않는다. 일반 계정은 처음 로그인한 상태에서도 등록 가게를 검색하고 즐겨찾기할 수 있다. 예시 그룹 3에 초대 코드 123456으로 가입하면 기존 선결제 기간 안에서 이용 가능 표시와 잔액을 확인할 수 있다. 초기 예시 선결제 이용 기간은 2026.10.28~2026.11.27이다.
