# 한턱 그룹 검색 화면 기획서

첫 이용자가 원하는 그룹을 발견하는 화면이다. 홈 맨 위 그룹 찾기로 진입한다.

## 구성과 검색 규칙

제목과 뒤로가기, 이름·코드·태그 입력란과 검색 버튼, 카테고리 필터, 결과 수, 그룹 카드 순서다.

- 이름, 공개 코드, 태그를 부분 검색한다. 영문 대소문자와 이름의 띄어쓰기 차이를 허용한다.
- 태그의 #은 결과에 영향을 주지 않는다. 여러 단어는 모두 일치하는 그룹을 찾는다.
- 카테고리는 전체, 학교·동문, 직장·팀, 취미·모임이다.
- 검색 버튼과 키보드 검색으로 갱신한다. 카테고리를 바꾸면 현재 검색어와 함께 바로 적용한다.
- 빈 검색어는 해당 카테고리 안에서 랜덤 순서로 표시한다. 첫 진입도 같은 방식이다. 예시가 3개라 전체에서는 3개가 모두 표시된다.
- 결과가 없으면 검색 결과가 없어요와 조건 변경 안내를 표시한다.

카드는 그룹 상세로 이동한다. 공개 코드와 초대 코드는 별개다. 초대 코드 123456은 그룹 검색 대상이 아니다.

## 예시 그룹

| 이름 | 공개 코드 | 카테고리 | 태그 | 가입 방식 |
| --- | --- | --- | --- | --- |
| 예시 그룹 1 | HG0001 | 학교·동문 | 대학생, 캠퍼스, 선후배 | 그룹장 승인 |
| 예시 그룹 2 | HG0002 | 직장·팀 | 직장인, 점심, 동료 | 그룹장 승인 |
| 예시 그룹 3 | HG0003 | 취미·모임 | 산책, 주말, 친목 | 초대 코드 |

공개 코드는 그룹별로 고유하다. 사진은 생성한 가상 썸네일이며 실제 단체를 나타내지 않는다.
