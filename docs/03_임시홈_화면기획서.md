# 한턱 홈 화면 기획서 초안

맨 위 그룹 찾기로 새로운 그룹을 검색하고, 아래 드롭다운으로 소속 그룹을 선택해 이용 가능한 가게를 확인한다. 처음 이용하는 사람은 소속과 가게가 모두 0개다.

## 구성과 이동

| 구성 | 동작 |
| --- | --- |
| 그룹 찾기 | 그룹 검색으로 이동 |
| 내 소속 그룹 | 승인 또는 초대 코드 가입이 완료된 소속만 드롭다운에 표시 |
| 정사각형 버튼 | 소속 그룹 리스트 화면으로 이동 |
| 그룹장 신청 알림 | 그룹장에게만 표시 |
| 가입 신청 | 신청자의 승인 대기 상태 표시 |
| 이용 가능한 가게 | 선택한 그룹의 사용 가능한 선결제 가게와 사용액·잔액·기간 표시 |
| 계정 | 이름, 아이디, 로그아웃 |

가입 대기는 소속으로 세지 않는다. 즐겨찾기만 한 그룹도 소속에 포함하지 않는다. 처음 소속이 생기면 자동 선택하고, 여러 소속은 드롭다운으로 바꾼다.

예시 그룹 3에는 예시 가게 1이 연결되어 있다. 해당 그룹을 선택하면 홈에서도 같은 선결제 정보를 표시한다. 다른 예시 그룹과 아직 소속이 없는 상태는 가게가 없는 안내를 표시한다.

계정·신청·승인·소속·즐겨찾기는 같은 앱 실행 안에서 유지되며 새로고침 시 초기화된다.

같은 가게에 선결제가 여러 건이면 가게 카드 하나에 건수와 합계 금액을 표시한다. 여러 건의 기한은 가장 빠른 기한으로 요약하고, 카드를 눌러 해당 그룹의 선결제별 기한과 잔액을 확인한다. 다른 소속 그룹의 금액은 합산하지 않는다.

선결제 가게 카드를 누르면 가게 상세에서 정보와 메뉴를 확인한다. 하단에는 홈·가게 찾기·별표 즐겨찾기 바를 고정한다. 가게 찾기는 소속 그룹과 관계없이 앱에 등록된 모든 가게를 검색하고 즐겨찾기하는 화면이다. 홈의 이용 가능한 가게 영역은 선택한 소속 그룹의 선결제를 기준으로 표시한다.
