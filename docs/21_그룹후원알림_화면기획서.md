# 한턱 그룹 후원 알림 화면 기획서

그룹장 계정 홈의 그룹 후원 알림 버튼을 누르면 진입한다. 기존 그룹 가입 신청 알림은 별도로 유지한다.

상단에는 뒤로가기·그룹 후원 알림 제목, 도착한 후원 건수와 안내를 둔다. 아래에는 최신 후원부터 금액 후원과 선결제 후원을 함께 나열한다. 각 카드에 방식·금액·그룹·후원자·결제일을 표시하고, 선결제일 때만 가게와 기한을 추가한다.

로그인한 사용자가 그룹장인 그룹의 후원만 표시한다. 다른 그룹장과 일반 사용자에게는 해당 내역을 제공하지 않는다. 후원이 없으면 빈 상태를 보여준다.

체험은 일반 계정으로 예시 그룹 1에 후원한 후, 새로고침하지 않고 로그아웃하여 leader01 / welcome123!로 로그인하면 된다. 외부 푸시 대신 앱 내부 알림함으로 확인한다.
