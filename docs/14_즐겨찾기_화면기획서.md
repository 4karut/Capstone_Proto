# 한턱 즐겨찾기 화면 기획서

하단 고정 바의 별표 즐겨찾기를 누르면 진입한다. 상단에 즐겨찾기 그룹과 즐겨찾기 가게 탭을 두며 각 개수를 표시한다. 최초에는 그룹 탭을 열고, 같은 로그인 실행 중에는 선택한 탭을 유지한다.

## 목록과 이동

| 탭 | 표시 정보 | 선택 결과 |
| --- | --- | --- |
| 즐겨찾기 그룹 | 이름, 기존 썸네일, 한 줄 소개, 카테고리·코드, 태그, 하트 | 그룹 검색과 동일한 그룹 상세 화면 |
| 즐겨찾기 가게 | 이름, 기존 사진, 한 줄 소개, 주소, 태그, 이용 가능 상태, 하트 | 가게 찾기와 동일한 가게 상세 화면 |

그룹의 가입 여부에 따라 같은 상세 화면에서 가입 신청 또는 소속 그룹의 선결제 정보를 표시한다. 즐겨찾기에서 시작한 가입 신청도 완료 확인 후 홈으로 돌아간다. 즐겨찾기만으로 그룹에 가입되지는 않는다.

그룹·가게 상세의 하트로 지정 또는 해제한다. 소속 그룹이 없는 사용자도 가게 찾기의 전체 가게에서 원하는 곳을 열고 즐겨찾기할 수 있다. 해제 후 목록으로 돌아오면 해당 항목은 사라진다. 그룹과 가게 목록은 서로 독립적이며 각 계정의 즐겨찾기만 표시한다.

목록이 비면 하트를 누르는 방법을 안내한다. 그룹 탭은 그룹 찾기 버튼을, 가게 탭은 가게 찾기 이동 버튼을 제공한다. 가입 그룹에 사용 가능한 선결제가 없어도 이미 즐겨찾기한 가게는 보존하고 이용 불가 상태를 안내한다.

현재 정렬은 예시 데이터의 등록 순서다. 즐겨찾기는 같은 앱 실행 중 화면 이동과 로그아웃·재로그인에 유지하며 새로고침·재시작하면 초기화된다.

## 하단 고정 바

홈, 가게 찾기, 별표 즐겨찾기, 사람 모양 마이페이지 네 항목을 표시한다. 로그인 후 주요 화면과 그 안에서 여는 그룹·가게 상세에서 유지하며, 스크롤해도 화면 아래에 고정한다. 다른 항목을 누르면 해당 항목의 기본 화면으로 이동한다. 회원가입·로그인·인증 완료 화면에는 표시하지 않는다.
