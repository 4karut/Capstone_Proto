# 한턱 가게 신청 심사 목록 화면 기획서

관리자 admin01 / welcome123!로 로그인한 뒤 마이페이지의 가게 신청 심사를 누른다. 일반 사용자와 가게 주인은 이 버튼과 심사 내역에 접근할 수 없다.

상단 뒤로가기·가게 신청 심사 제목 아래 심사 대기 건수를 표시한다. 최신 신청부터 가게 이름·카테고리·신청자 이름·주소를 카드로 나열한다. 카드를 누르면 해당 신청 정보 화면으로 이동한다.

승인·반려된 차수는 대기 목록에서 제외한다. 재신청이 접수되면 새 차수를 심사 대기로 표시하고 차수와 재신청 문구를 보여준다. 카드를 누르면 수정된 제출 정보와 이전 이력 확인 버튼이 있는 상세를 연다. 대기 내역이 없으면 빈 상태를 표시한다. 관리자 권한은 미리 등록한 체험 계정에만 부여하고 같은 이름의 일반 회원가입으로 획득할 수 없다.
